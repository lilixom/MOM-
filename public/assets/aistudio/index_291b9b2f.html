P1 · 主页面

工艺参数列表

按组织机构、产品料号、生产工序筛选；上方为主参数列表，中部为物料参数明细，底部为下发组织记录。

进入页面 →
F2 · 模态弹窗

新增-工艺参数

产品料号、生产工序必填；明细表格初始为空，可通过「+新增」逐行添加物料参数，保存后回写列表。

打开弹窗 →
F3 · 模态弹窗

修改-工艺参数

产品料号、生产工序只读；明细表格带 11 行示例数据（编号 2-12），可编辑项目名称/项目类型，支持批量删除。

打开弹窗 →
F4 · 浮层面板

列设置

勾选字段实时控制主表格列显隐，支持恢复默认。

打开面板 →
F5 · 模态弹窗

物料代码选择

点击明细表物料代码的放大镜触发；单选物料后回填物料代码与物料名称。支持料号/名称搜索。

打开弹窗 →
筛选查询 → 选中主参数行 → 查看 / 修改（联动明细） → 下发组织记录
页面结构：主列表字段为 组织机构 / 产品料号 / 产品名称 / 产品规格 / 产品版本 / 工艺版本 / 工序名称 / 工序编码 / 操作；物料参数明细为 物料料号 / 物料名称 / 项目名称 / 项目类型 / 必须标示 / 固定值 / 下限值 / 上限值 / 单位；下发记录为 下发组织 / 下发时间 / 下发人员。
待确认：① 产品料号/生产工序的选择弹窗数据源；② 项目类型下拉选项（示例为「记录值」）枚举；③ 「必须标示」开关开启后的联动；④ 「下发」操作是否需要选择组织与时间。
