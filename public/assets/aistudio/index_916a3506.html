P1 · 主页面

BOM 列表

组织机构 + 4 组筛选（BOM编号 / 产品名称 / 工厂 / 产品料号）；工具栏 提交SAP / 确认 / 驳回 / 工艺BOM合并 / 添加BOM / 删除；表格 8 列 + 操作列。

进入页面 →
P2 · 全屏表单

BOM添加

两列 13 字段：父项物料号（必填）、类型、工厂、行项目数、基本数量、生效日期、有效期、BOM文本、BOM用途、项目类别、版本可选BOM、外补涂客户、内补涂客户；底部「保存并退出 / 取消」。

打开表单 →
P3 · 全屏表单

编辑BOM-标题

上部两列 14 字段（部分只读灰底）；下部组件明细表 9 行，工具栏 添加一行 / 导入 / 根据工艺单生成组件 / 生成默认数据 / 删除；底部「保存并退出 / 取消」。

打开编辑 →
F3 · 浮层面板

列设置

勾选字段实时控制 BOM 列表列显隐，可显示创建人 / 创建时间，支持恢复默认。

打开面板 →
F4 · 浮层弹窗

导入组件

选择 Excel / CSV 导入，模拟向编辑BOM 的组件明细追加一行。

打开导入 →
F5 · 浮层弹窗

选择组件

按组件号 / 组件描述搜索并单选，回填明细行的组件、组件描述与数量；明细表双击「组件」单元格也可打开。

打开选择 →
