页面流程总览
昇兴排程系统 · 计划管理 · 由 4 张 Axure 静态图还原的可交互原型（点击卡片进入对应页面 / 浮层）
P1 · 主页面

计划单列表

筛选区 + 数据表格 + 分页。集中管理计划单，支持查询、同步、新增、转工单、列设置等操作。

进入页面 →
F1 · 弹窗

同步

由列表页「同步」按钮唤起。按工厂、物料料号、日期范围筛选后从上游同步计划数据。

打开浮层 →
F2 · 弹窗

工单信息

由「新增 / 修改 / 转工单」唤起。含工单主表单与工单 BOM 明细，支持保存与数量计算。

打开浮层 →
F3 · 浮层

列设置

由工具栏齿轮唤起。勾选字段可实时控制列表列的显示 / 隐藏，支持固定与排序占位。

打开浮层 →
列表页 P1 → 同步 F1　·　 列表页 P1 → 工单信息 F2　·　 列表页 P1 → 列设置 F3
交互说明：本原型还原自 Axure 页面「计划单」（原稿仅有 4 张静态图片，未定义交互）。 已补齐的交互包括：筛选与查询、重置、表格单选 / 全选、行高亮、修改 / 删除 / 转工单、同步校验、 工单表单编辑与必填校验、开关切换、BOM 增行、列显隐联动、分页与各类反馈提示。 红色批注项见各浮层底部，为待业务确认内容。
